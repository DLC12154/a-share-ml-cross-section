# 方法与数据限制

## 数据源

项目复制自原 `csi300-momentum-research` 项目的冻结文件：

- 行情：`data/raw/csi300_prices_historical.parquet`
- 行情SHA-256：`3f13a8eafb9138ff33a8c0807f143782f229c25f5fac8e3a7e4f7a74f4820a23`
- 历史名单：`data/reference/csi300_historical_membership.csv`
- 日期：2019-07-01至2025-12-31；正式研究截面为2020-01-02至2025-12-25
- 记录：731,507行
- 股票：481只历史成员并集
- 数据源：Baostock后复权日线

行情文件的内容哈希在运行开始时校验，文件变化会中止实验。

## 股票池

历史名单有481只股票、291个查询日、87,300条成员记录，行情覆盖全部481只股票。

实现直接以历史名单的`query_date`作为信号日，不再另行构造可能错位的五日相位。该方法避免了用当前成分回溯，但名单只保存五日网格快照，不是逐日成分股。

信号日的可选股票必须同时满足：

- 属于该查询日的历史名单。
- `tradestatus = 1`，且成交量大于零。
- 当日不是ST。
- 在此前至少有120个可交易日。
- 20日平均成交额不低于3,000万元。

该过滤不改变第二天的可成交性，也不模拟涨跌停阻塞；因此信号评价和解析组合评价仍不能替代原动量项目的可执行账本。

## 时间定义

在统一市场交易日历中：

```text
signal_date = t
entry_date  = t+1
label_end   = t+6
future_return = open[t+6] / open[t+1] - 1
```

每5个市场交易日生成一次横截面信号。训练数据要求 `label_end_date < validation_start`，验证数据要求 `label_end_date < test_start`。时间外验证期预测包含未来收益暂时缺失的股票；RankIC计算时排除缺失值，组合评价把缺失收益按0处理并输出覆盖率。未来收益完全缺失的持有期不进入组合绩效。

## 特征

主实验使用15个价格派生特征：

- 1、5、10、20、60、120日收益。
- 5、20、60日单日收益波动率。
- 相对5、20、60日均线的偏离。
- 20、60日价格区间位置。
- 当日振幅。

每个交易日仅在可选股票池内计算百分位排名，再减去0.5。缺失特征统一填0，不跨股票使用未来统计量。

价格类特征使用向前填充后的收盘、最高和最低价形成连续市场日窗口；当日振幅仍使用原始价格。信号日必须实际可交易，因此不会在停牌日选股。

成交量、换手率或成交额特征默认关闭。成交额只用于信号日流动性过滤；Baostock后复权口径和公司行为尚未独立全面复核。

## 模型

- `momentum_20`：20日横截面动量直接排序。
- `factor_composite`：15个横截面特征的算术平均。
- `ridge`：验证期从0.1、1、10、100中选择alpha；最终在训练加验证期重训。
- `mlp`：两层64/32隐藏单元，ReLU，Adam，L2正则；使用7、19、31三个种子平均预测。
- `lightgbm`：回归树模型，验证期早停；最终在训练加验证期按固定轮数重训。

训练目标为同日未来收益的横截面百分位减0.5，不是绝对收益。

## 组合与成本

- 每5个市场交易日调仓。
- 选预测最高的20%可选股票。
- 目标权重等权，纯多头。
- 单边成本按买入和卖出成交额分别计费。
- 主成本为10bps；同时计算5bps和20bps。
- 基准为同一可选股票池、同一调仓日的等权组合，并采用相同成本口径。
- 这是统一的解析组合评价，不包含原动量项目高级回测中的涨跌停阻塞、ADV容量和逐日现金账本。

换手率定义为半L1权重变化：

```text
one_way_turnover = 0.5 * sum(abs(weight_t - weight_t-1))
cost = sum(abs(weight_t - weight_t-1)) * one_way_cost_rate
```

## 结果解释

RankIC表示同一天预测排序与实际未来收益排序的相关性。ICIR为RankIC均值除以RankIC标准差，本报告不年化。组合年化收益按每5个交易日一个周期几何年化，Sharpe使用同一周期频率，无风险利率设为0。

结果只能用于研究流程展示。逐日成员、完整公司行为核验和逐日执行账本尚未接入ML实验。
