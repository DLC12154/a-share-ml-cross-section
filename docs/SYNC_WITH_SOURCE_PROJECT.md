## 未同步

神经网络实验复用了信号研究层，没有直接复用原项目的逐日交易账本：

- 未模拟开盘涨停导致无法买入后继续等待或替换。
- 未模拟开盘跌停或停牌导致无法卖出后的持仓延期。
- 未施加单笔成交额不超过20日平均成交额5%的容量约束。
- 未计入最低5元佣金、卖出印花税差异及逐日现金。

因此两套组合收益不能直接等同。原项目的可执行长仓结果保存在：

- `data/reference/original_advanced/executable_performance.csv`
- `docs/source_project_advanced_validation.md`

原项目修正未来收益缺失入样问题后，2024-2025年Q5扣成本总收益为39.74%，Sharpe为0.833。原项目与Git历史已经包含该区间结果，因此不称为锁定OOS。

神经网络的模型比较仍使用统一的简化周频组合评价，重点检验预测排序是否有增量，不宣称已经完成同等强度的可执行回测。
