# 原动量项目高级结果快照

本目录只保存与改进后 `csi300-momentum-research` 的口径核对材料：

- `rank_ic_by_stage.csv`
- `executable_performance.csv`
- `data_quality.json`
- `run_metadata.json`

这些文件来自原项目，不由本仓库实验入口自动更新。当前共享动量代码用于统一因子和ML信号口径；原项目的可执行交易账本包含涨跌停、成交容量和逐日现金约束，其组合收益不能与本仓库的简化解析组合直接等同。

集成测试核对20日动量在2024-2025年96个截面上的Mean RankIC与原项目一致，为-0.014042。
